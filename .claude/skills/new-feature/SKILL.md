# new-feature

Скаффолдит новую фичу по конвенции, заданной `architect`-агентом.

## Шаги

1. Если имя фичи не указано или неясно, что она делает — спроси у Давида, прежде чем
   создавать структуру.
2. Имя папки — `kebab-case`, в `src/features/<name>/`.
3. Создавай только те подпапки, которые реально нужны фиче — не создавай пустые заглушки:
   - `components/` — если есть собственные презентационные компоненты
   - `hooks/` — если есть кастомная логика/состояние
   - `api/` — только если фича обращается к внешним данным
   - `types.ts` — типы, специфичные для фичи
4. `index.ts` — barrel-экспорт только публичного API фичи (то, что реально используется
   снаружи через `src/app/`) — не экспортируй внутренние детали реализации.
5. Правило границ: эта фича не импортирует напрямую из другой `src/features/*` — только
   через `src/shared/*`. Если нужно что-то общее — вынеси в `shared`, а не дублируй.
6. После скаффолда — реализацию самого функционала передавай агенту `frontend-developer`,
   этот скилл только готовит структуру, не пишет бизнес-логику.
