# Hay Travel — контекст проекта

Общие правила и команда агентов — в корневом [agents.md](../agents.md). Здесь — то, что
привязано конкретно к этому проекту.

## Цель проекта
Писать фронтенд (клиентский сайт + админка) с архитектурным подходом, на уровне Senior
Frontend Developer.

## Стек
- Vite + React + TypeScript + Tailwind CSS.
- Причина выбора: проект должен собираться в статику и деплоиться на Netlify/любой другой
  статический хостинг практически без ручной настройки (пользователь не занимается фронтендом
  и не должен разбираться в конфигурации).
- Проект стартовал с нуля.

## Структура
- `Frontend/` — клиентский сайт + админка (`/admin`), общий слой `shared`.
- `Backend/` — бэкенд.
- `docs/` — модульная документация проекта, обновляется после каждой фичи:
  - [client-site.md](docs/client-site.md) — публичная часть.
  - [admin-panel.md](docs/admin-panel.md) — админ-панель.
  - [backend-api.md](docs/backend-api.md) — контракт бэкенда.
  - [product-model.md](docs/product-model.md) — доменная модель (тур/экскурсия и т.д.).
  - [CHANGELOG.md](docs/CHANGELOG.md) — история изменений.
