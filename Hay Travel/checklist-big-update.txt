РЕШЕНИЯ, ПРИНЯТЫЕ ДАВИДОМ
-------------------------
1. Скрин 1: drag-handle панели региона нерабочий — нужен реальный
   свайп (вверх/вниз), сейчас закрывает только крестик.
2. Мобильный тап по региону: 1-й тап = подсветка + мини-подсказка
   («Гегаркуник · 1 тур» + кнопка «Смотреть»), панель — только по кнопке.
3. Light-палитра: тёплый пергамент + бордо/золото.
4. Hero-изображение — только из настроек админки (URL).
5. «Сочная картинка» = кинематографичный визуал + живые анимации.
6. Setup в админке: hero-блок целиком + контакты/соцсети + логотип/SEO.
7. Справочники: ссылка на каталог + per-tour override.
   Правка в каталоге меняет ВСЕ туры, КРОМЕ тех, где значение
   переопределено вручную в конкретном туре.
8. Пункт меню: «Справочники».
9. Клиентский сайт переводим на реальный API в этой же работе.
10. Армянский язык НЕ нужен. RU/EN. Архитектура — расширяемая
    под новый язык без переделки.
11. Restriction + OrganizationalDetail сливаем в одну сущность с Type.
12. Порядок: Баги -> Дизайн -> Бэк -> Админка -> Клиентский сайт.

РЕШЕНИЯ, ПРИНЯТЫЕ ГЛАВНЫМ АГЕНТОМ (архитектурные)
-------------------------------------------------
- Ереван: рендерим реальный SVG-path (геометрия есть, просто
  отфильтрована как isEnclave), делаем кликабельным.
- Регионы: сущность в БД (Region + RegionTranslation + seed 11),
  геометрия SVG остаётся на фронте как ассет отрисовки.
- Cursor: одно глобальное правило в index.css (Tailwind 4 убрал
  cursor:pointer из preflight), а не 27 точечных правок.
- SiteSettings: key-value с переводами и флагом IsPublic.
- Новые контроллеры пишем в текущем стиле проекта (без DI),
  перевод всего бэка на DI — отдельная задача техдолга.
