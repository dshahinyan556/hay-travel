   `flex-wrap`-ряда. Ни один контрол не задублирован в DOM — раскладка через responsive `order`
   + невидимые `basis-full`-спейсеры на брейкпоинт. Заодно вскрыт и исправлен реальный баг:
   `RegionMultiSelect` не сжимался внутри `flex-1`-ячейки (не было `min-w-0`), вылезая на
   соседний контрол. Подробности — `docs/client-site.md`.
3. **`PriceSortControl.tsx`** — кнопка-триггер больше не показывает диапазон/сортировку текстом,

4. **Подпись «Регион» убрана из ряда фильтров** — остался только сам контрол (`<label>` стал
   `sr-only`, имя для скринридера не потерялось). На мобильном ряду 3 это заодно сделало Регион
   и Цену равными по ширине — без подписи с собственной шириной оба `flex-1`-контрола делят ряд
   поровну и заполняют его целиком.

- `bg-wine` намеренно **не** переведён на `bg-accent`: в тёмной теме `accent` — это золото, и активная вкладка стала бы золотой заливкой со светло-золотым текстом. Литерал `#8e1b38` корректен в обеих темах (7.63:1 на пергаменте).

**Карта регионов (пункт 1.8).** 8 hex-литералов в `ArmeniaMap.tsx` заменены на `var(--map-*)`. Регион «без туров» больше не рисуется через `opacity: 0.55` (она гасила заодно обводку и подпись) — у него свой токен заливки. Подписи используют `--map-label` + halo `--map-label-halo` с `paint-order: stroke`, поэтому читаются и над обычной заливкой, и над бордовой заливкой выбранного региона. Добавлены токены тултипа карты (`--map-tooltip-bg` / `-edge` / `-text` / `-text-muted`): в светлой теме тултип белый с золотой рамкой и тенью `--shadow-md`, в тёмной остался прежним; заголовок и счётчик туров в нём переведены с золотых литералов на `accent-strong` / `gold-ink` — на белом фоне золото давало 1.39:1.

**Переключатель языков (пункт 1.7).** Кнопка HY убрана, остались RU/EN. Список локалей вынесен в новый `Frontend/src/shared/lib/locale.ts`: `LOCALES` (дескрипторы), тип `Locale` выведен из этого списка, `DEFAULT_LOCALE`, type guard `isLocale`, безопасный `normalizeLocale` (неизвестная локаль падает в дефолт). Переключатель рендерится из списка — новый язык добавляется в одном месте. Реального i18n-слоя в проекте нет вообще: ни библиотеки, ни словарей, HY существовал только строкой в разметке; в админке HY не было изначально; персистентности выбранного языка нет — выбор живёт в `useState`.

**Проверено в браузере:** 1281×860 и 375×812, главная и `/regions`, обе темы — карта пергаментная, hover даёт золотую заливку, выбранный регион бордовый с золотой обводкой, тултип читаем в обеих темах. Контрасты светлой темы: бордо на фоне 7.63:1, бронза 6.90:1, подпись региона 10.04:1, текст по золотой заливке 7.87:1, заголовок тултипа 10.6:1 — AA проходит везде.
