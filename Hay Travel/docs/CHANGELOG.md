## 2026-07-26 — Светлая тема: рефактор токенов, карта регионов на токенах, переключатель языков RU/EN

**Рефактор токенов (этап 2.2).** До этого между темами переключались только 9 переменных — из-за этого светлая тема выглядела грязной, а карта регионов оставалась чёрной. Сделано двухслойно: в `Frontend/src/index.css` объявлены парные роль-переменные для **обеих** тем (значения светлой взяты дословно из утверждённого `light-palette-tokens.css`, значения тёмной подобраны так, чтобы тёмная тема осталась визуально идентичной прежней), а через `@theme` каждый роль-токен получил алиас `--color-*` — в компонентах работает обычная утилита Tailwind (`border-edge`, `text-gold-ink`, `bg-accent-soft`) без префиксов `dark:`/`light:`.
- **Золото разложено по ролям, а не по оттенкам:** `gold-ink` — текст (в светлой теме это бронза `#6b4a15`, потому что золото как текст на пергаменте даёт 1.86:1), `gold-line` — границы, `gold-fill` + `gold-on` — заливка и текст поверх неё. Главный акцент светлой темы — бордо `#8e1b38`, тёмной — золото.
- **Объём:** мигрировано 44 использования `hairline` (токен `--color-hairline` удалён полностью), 115 из 139 `gold*`, 9 из 24 `wine*`; затронуто 23 файла. Удалён неиспользуемый `--color-wine-deep`.
- **Осознанное исключение, «дочищать» нельзя:** элементы поверх гарантированно тёмного фона — hero, чипы на фотографиях — остаются на фиксированных литералах `gold`/`cream`. Hero тёмный в обеих темах, тема-зависимый токен дал бы там тёмное на тёмном. Именно поэтому 24 из 139 `gold*` и 10 из 24 `wine*` не мигрированы — это не недоделка.
- `bg-wine` намеренно **не** переведён на `bg-accent`: в тёмной теме `accent` — это золото, и активная вкладка стала бы золотой заливкой со светло-золотым текстом. Литерал `#8e1b38` корректен в обеих темах (7.63:1 на пергаменте).

**Карта регионов (пункт 1.8).** 8 hex-литералов в `ArmeniaMap.tsx` заменены на `var(--map-*)`. Регион «без туров» больше не рисуется через `opacity: 0.55` (она гасила заодно обводку и подпись) — у него свой токен заливки. Подписи используют `--map-label` + halo `--map-label-halo` с `paint-order: stroke`, поэтому читаются и над обычной заливкой, и над бордовой заливкой выбранного региона. Добавлены токены тултипа карты (`--map-tooltip-bg` / `-edge` / `-text` / `-text-muted`): в светлой теме тултип белый с золотой рамкой и тенью `--shadow-md`, в тёмной остался прежним; заголовок и счётчик туров в нём переведены с золотых литералов на `accent-strong` / `gold-ink` — на белом фоне золото давало 1.39:1.

**Переключатель языков (пункт 1.7).** Кнопка HY убрана, остались RU/EN. Список локалей вынесен в новый `Frontend/src/shared/lib/locale.ts`: `LOCALES` (дескрипторы), тип `Locale` выведен из этого списка, `DEFAULT_LOCALE`, type guard `isLocale`, безопасный `normalizeLocale` (неизвестная локаль падает в дефолт). Переключатель рендерится из списка — новый язык добавляется в одном месте. Реального i18n-слоя в проекте нет вообще: ни библиотеки, ни словарей, HY существовал только строкой в разметке; в админке HY не было изначально; персистентности выбранного языка нет — выбор живёт в `useState`.

**Проверено в браузере:** 1281×860 и 375×812, главная и `/regions`, обе темы — карта пергаментная, hover даёт золотую заливку, выбранный регион бордовый с золотой обводкой, тултип читаем в обеих темах. Тёмная тема совпадает с прежней до литерала (`#17120c`, `#6b5426`, `#c9b896`, CTA `#d9b45a`/`#0f0c08`). Контрасты светлой темы: бордо на фоне 7.63:1, бронза 6.90:1, подпись региона 10.04:1, текст по золотой заливке 7.87:1, заголовок тултипа 10.6:1 — AA проходит везде.

**Открыто:** контраст региона «без туров» отличается от обычного всего на 1.12:1 (значение из утверждённого мокапа, прежний `opacity: 0.55` гасил заметно сильнее) — нужно решение Давида; на 375px 12 кликабельных элементов меньше 44×44 (кнопка темы и меню — 40px, пилюли языка — 36px) при минимуме 44 в утверждённой палитре; мёртвое поле `hy` с армянскими названиями 11 марзов в `shared/data/armeniaMarzes.ts` (обращений в коде нет); `<html lang="en">` в `index.html` при русском контенте. Тема на реальном Android Давидом ещё не проверена (пункт 1.4 открыт). Этапы 2.3 (кинематографичный визуал) и 2.4 (анимации) не начаты, полная проверка обеих тем (2.5) — после них.

## 2026-07-25 — Публичный сайт: старт с нуля, дизайн «тёмный люкс», регионы-марзы
- Утверждено дизайн-направление публичного сайта: обсидиан + золото + вино, Cormorant + Inter, только свои line-иконки (эмодзи запрещены). Первая, песочно-розовая палитра (гранат `#C21F45`) забракована.
- Публичный каркас пересобирается **с нуля**: старые `features/home` и `features/tours` (teal-палитра, направления Армения/Грузия/ОАЭ) удаляются. Админка не затрагивается. Сайт — **только Армения**.
- Добавлен домен **регионов (11 марзов)**. Геометрия карты взята из открытых geo-данных **geoBoundaries ADM1** и сконвертирована в SVG-пути (`viewBox 0 0 1000 1009`, каждый марз — отдельный `<path>`); Ереван — маркер-точка (анклав). Платный сток-вектор не копировался — авторские права. Стилизованные «низкополи» контуры забракованы.
- Регионы пока **на моках**; бэкенд (`Region` + EF-миграция + M2M `Tour↔Region` + эндпоинты) — отдельным этапом.
- Зафиксированы два требования по замечаниям заказчика: карточки тура выравниваются по низу (`mt-auto`) с обрезкой заголовка `line-clamp` — цена в ряду на одном уровне; у марзов карты убирается `outline`-прямоугольник, но `:focus-visible` остаётся своим стилем (доступность с клавиатуры сохранена).
- Новый док: [client-site.md](client-site.md).

**Реализовано (фронтенд публичной части):**
- Токены люкс-палитры в `index.css` (dark по умолчанию + light по `data-theme`), шрифты Cormorant + Inter. `brand-*` (teal) сохранён — это палитра админки.
- Удалены старые `features/home` и `features/tours`; собраны заново: главная (hero + витрина + тизер карты + отзывы), каталог с фильтрами в URL (`useTourFilters`), детальная (галерея, таймлайн по дням, включено/не включено, блок брони с предоплатой 20%), логин/регистрация (UI), 404 и error boundary.
- `/tours` и `/excursions` — одна страница с разным `lockedKind`. Новые роуты: `/regions`, `/excursions`, `/login`.
- **Регионы**: `shared/data/armeniaMarzes.ts` (метаданные 11 марзов) + `marzGeometry.ts` (SVG-пути, ~37KB, отдельным модулем и lazy-чанком). `features/regions` — карта с 5 состояниями, панель туров (десктоп сбоку / мобайл bottom-sheet), 4 состояния панели (загрузка/пусто/ошибка/готово).
- Свой набор inline-SVG line-иконок (`shared/ui/icons.tsx`), эмодзи нет. Чипы `KindChip`/`BadgeChip` (тур = вино+луна, экскурсия = золото+солнце).
- Установлен `framer-motion`. Локальные SVG-заглушки изображений в `public/placeholders/`.

**Исправлено по замечаниям Давида:**
- **Карточки выровнены**: `h-full` + `flex-col` + `mt-auto` на футере — цена всех карточек в ряду на одной высоте; заголовки/описания обрезаются `line-clamp-2`. Проверено стресс-тестом с длинным заголовком.
- **Убран прямоугольник вокруг марза**: `outline: none` на `.marz-path`, взамен `:focus-visible` даёт золотой stroke — доступность с клавиатуры сохранена.

**Попутные исправления:** цвета убраны с `body` (протекали в админку кремовым текстом); литеральные `text-cream*` заменены на тема-зависимые `text-ink*` кроме тёмных поверхностей; отдельный тёмный градиент `.text-gold-sheen` для светлой темы; тап-зоны увеличены до 36–40px; мобильная шторка переведена на CSS keyframes.

**Не сделано (следующие этапы):** бэкенд регионов (`Region` + миграция + M2M + эндпоинты), реальный API вместо моков, реальные фото, функциональные бронирование/авторизация/отзывы, локализация строк EN/HY.
