ДИАГНОЗ (подтверждён исследованием кода)
-----------------------------------------
Баг 1: TourDiscountExtensions.ApplyDiscount() при отсутствии активной
скидки возвращает исходную цену вместо null. Контракт "DiscountedPrice
== null значит скидки нет" нарушен -> любой тур с ценой выглядит как
скидочный на фронте (TourCard.tsx проверяет только "!== null").

Баг 2: OrderCreationService.cs:81 и OrderLineService.cs:44 вызывают
ResolveActiveDiscountPercent() БЕЗ даты тура — сравнение идёт с
сегодняшней датой оформления заказа, а не с датой самой поездки.
Бронь на день после DiscountValidUntil всё равно получает скидку.

РЕШЕНИЯ, ПРИНЯТЫЕ ДАВИДОМ
--------------------------
1. Добавить дату НАЧАЛА скидки (DiscountStartDate) — сейчас в модели
   есть только дата окончания. Скидка активна в диапазоне [start; end].
2. Красная лента в календаре = полоса с процентом скидки (например
   "-15%") поверх числа дня.
3. Лента нужна только в календаре бронирования на клиентском сайте
   (DatePicker при выборе даты тура). В админке — не требуется.
